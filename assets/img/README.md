# Projektbilder

Hier kommen die Bilder für die Projektkarten rein. Jedes Projekt erwartet
genau **einen** Dateinamen (jpg, png oder webp – Endung im HTML ggf. anpassen).

Solange keine Datei existiert, zeigt die Karte den Farbverlauf als Platzhalter –
es bricht also nichts, wenn ein Bild noch fehlt.
